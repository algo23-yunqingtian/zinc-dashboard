# 锌(Zn)看板 · 分析框架与整体构架

> 用途：本文档定义锌看板的**整体架构**与**分析框架（AI 解盘评分）产出过程**，
> 是 `zinc_scoring.yaml` 的设计依据。对应镍版 `docs/analysis_frame.md`，
> 由 ZINC_HANDOFF.md 第 7-9 节复刻而来。

---

## 0. 一句话定位

锌的核心矛盾 = **矿端紧缺（锌精矿 TC）↔ 冶炼产能/利润博弈**，需求端由**镀锌（地产/基建）**主导。
AI 解盘不堆砌数据，而是把 18 张图压缩成「几条可反驳的核心矛盾」，再让模型据此产出 6 步解盘。

---

## 1. 整体构架（系统分层）

```
┌──────────────┐   ┌─────────────────┐   ┌──────────────────┐
│ 数据源        │   │ 数据层           │   │ 展示/解盘层        │
│ Zhiji 行情    │──▶│ fetch_zn.py     │──▶│ index.html       │
│ SMM/Mysteel  │   │  → data.json    │   │  + static/       │
│ 问财/AI 研报  │   │  (18 charts)    │   │    charts.js     │
└──────────────┘   └─────────────────┘   └──────────────────┘
                                                │
                          ┌─────────────────────┼─────────────────────┐
                          ▼                     ▼                     ▼
                   A 核心矛盾(4)         B 基本面(14图)          AI 解盘(V2)
                   (LME库存/进口窗口/     (SHFE/LME价/持仓/       analyze_zn.py
                    锌精矿TC/冶炼利润)     沪伦比/库存/利润/        + zinc_scoring.yaml
                                          产量/表观消费)          + scorer_v2_zn.py
```

- **数据层**：`fetch_zn.py` 每 30min 通过 GitHub Actions 跑，产出 `data.json`（唯一数据源）。
- **展示层**：`index.html` + `static/charts.js` 纯前端渲染，不依赖服务器。
- **解盘层**：`analyze_zn.py` 在服务器端实时调用 SiliconFlow/Qwen 产出解盘；GitHub Pages 显示缓存。

## 4. 分析框架产出过程（6 步 → 8 大矛盾 → 评分）

### 4.1 从"数据"到"矛盾"（降维）
18 张图不能直接喂给模型，先压缩成 **8 大核心矛盾**（`zinc_scoring.yaml` 的 `contradictions`）：

1. **矿端紧缺（锌精矿 TC）** — 矿紧不紧，TC 是锚
2. **TC/RC 加工费趋势** — 长单 TC 定全年矿端基调
3. **冶炼利润与开工** — 利润决定检修/减产节奏
4. **镀锌需求（地产/基建）** — 消费主线
5. **七地库存去化** — 库存是结果变量
6. **进口窗口（沪伦比）** — 内外价差
7. **宏观流动性** — 美元/降息/板块资金
8. **政策 / 环保限产** — 供给侧外生冲击

### 4.2 矛盾如何进入解盘
`analyze_zn.py` 用 `gv()` 从 `data.json` 取 18 指标 → 拼进 6 步 Prompt：
`技术面 → 核心矛盾 → 跨品种 → 资讯研报 → 资金 → 结论`。
矛盾清单即"核心矛盾"段的素材，模型据此给多空判断，**必须可反驳**（带数据支撑）。

### 4.3 新闻评分（A/B/C 三级 + 相关性闸门）
- **相关性闸门**（`relevance.core_terms` + `combos`）：命中锌核心词，或"限定词+锌产业词"组合，才纳入。
- **三级加权**（`tiers`）：A 级(直接定价, ×3.0) / B 级(情绪, ×1.5) / C 级(噪音, ×0.5)。
- **负向过滤**（`negative_filters`）：纯政治、无关商品、旧闻、重复 → 剔除。

### 4.4 框架自检九式（对照镍版）
1. 矛盾是否覆盖"矿端↔冶炼↔需求↔库存"四环节 ✓
2. 每条矛盾是否 bullish/bearish 双向 ✓
3. 相关性闸门是否防住无关商品 ✓
4. A 级是否都是"直接定价"事件 ✓
5. 负向过滤是否拦截旧闻/噪音 ✓
6. 数据键是否解释得通（见 §3）⚠️ 键名待清洁
7. Prompt 是否强制"可反驳+带数据" ✓
8. 跨品种对比是否含铜/铝/铅/镍/锡 ✓
9. 评分 ranking 是否 20 套 Prompt 可比 ✓
